# Makan Guide Kepong & Menjalara

A responsive restaurant listing website for Kepong and Menjalara.

## Run locally

Open `index.html` directly in a browser, or serve it using:

```bash
python -m http.server 8000
```

Then visit:

- http://localhost:8000

## GitHub Pages

This site is designed to work as a static GitHub Pages website. Upload the repository as-is and enable Pages from the repo settings.

## Mobile access

The layout is optimized for phone screens with responsive cards, stacked grids, safe-area padding, and touch-friendly buttons.
